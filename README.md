# МедиаПрокат

## Запуск

Нужен Node.js 24 или новее. Внешних зависимостей нет.

```bash
npm start          # http://localhost:3000
npm test           # тесты
npm run seed       # сбросить базу к демо-данным
```

При первом запуске создаётся `data/media-rental.db` с демо-данными. Сбросить их можно командой
`npm run seed` или кнопкой «Сбросить демо-данные» на экране входа.

Переменные окружения:

| Переменная | По умолчанию |
|---|---|
| `PORT` | `3000` |
| `HOST` | `127.0.0.1` |
| `DB_PATH` | `data/media-rental.db` |

Вход без пароля: на первом экране выберите пользователя, права определяются его ролью.
